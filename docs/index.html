How to use, step by step

SleepScope is a reading of the data, not a medical device. Nothing leaves this phone unless you use Ask Claude. The desktop version with Apple Health import is at github.com/robertb-design/sleepscope.

Synopsis

Pick a range. The rule based report is computed on the phone; Claude's reading follows if a key is saved.

Load data to see the synopsis.

Claude's reading

Save an API key on the Ask tab. Claude then writes its own account of the selected range: what the data shows, what it means, what to ask the prescriber. Runs by itself when data loads; the same data is not sent twice.

A week as terrain. One finger rotates, two fingers zoom. Newest night at the front.

How to read it
high green: breathing freelyyellow dip: airway narrowingred crater: airflow stoppedgrey floor: mask offblue pool: mask leaking (over 24 L/min)red pillar: obstructive apneaviolet pillar: central apneaorange pillar: hypopneawhite line: pressure delivered

Each strip is one night, evening on the left, morning on the right. Height is how freely you were breathing. A good night is a long flat green strip with no pillars and no water.
